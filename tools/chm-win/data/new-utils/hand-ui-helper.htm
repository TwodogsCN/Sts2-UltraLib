HandUiHelper 手牌 UI 操作辅助工具
StS2 原版手牌的视觉顺序与逻辑顺序不一致，此类提供在逻辑层操作手牌、 并自动同步到 UI 视觉层的静态方法（交换、洗牌、移动、对齐）。
所有改变手牌顺序的操作都会触发 Plus_TriggerBeforeHandPileMoved / Plus_TriggerAfterHandPileMoved Hook，方便其他模块（如 IsomorphismSingleton）响应手牌变化。

方法总览

方法作用
GetRawCards通过反射获取手牌内部 _cards 列表（原始可变引用）。
SwapPlayerHandCards交换两张手牌（索引版 / 引用版两种重载）。
SyncVisuals将手牌 UI 子节点顺序与逻辑列表对齐。
ShuffleHand用游戏 RNG 对手牌进行 Fisher-Yates 洗牌。
MoveToEdges把指定卡牌移到手牌最左或最右。

方法详解

获取原始列表：GetRawCards

public static List<CardModel>? GetRawCards(Player owner)

通过 Harmony AccessTools.Field 反射读取手牌牌堆的 _cards 字段，返回原始引用（可直接修改）。获取失败返回 null。注意：直接改这个列表不会自动同步 UI，请优先使用本类的其他方法。

交换手牌（索引版）：SwapPlayerHandCards

public static async Task SwapPlayerHandCards(Player owner, int indexA, int indexB)

按索引交换两张手牌。索引越界、相同或列表为空时直接返回。交换前对两张牌触发 Before Hook，交换后触发 After Hook，并同步视觉层。

交换手牌（引用版）：SwapPlayerHandCards

public static async Task SwapPlayerHandCards(Player owner, CardModel cardA, CardModel cardB)

按卡牌引用交换。会在执行前实时查找索引，并在触发 Before Hook 后重新索引，防止 Hook 的异步操作导致索引偏移。任一张不在手牌中则直接返回。

同步视觉：SyncVisuals

public static void SyncVisuals(Player owner, List<CardModel> cardsList)

建立 CardModel → NHandCardHolder 映射，用 MoveChild 把每个 holder 移动到与逻辑顺序一致的索引，最后调用 ForceRefreshCardIndices 刷新卡牌交互索引。无 UI 或容器无效时直接返回。

洗牌：ShuffleHand

public static async Task ShuffleHand(Player owner)

用 RunState.Rng.Shuffle 做 Fisher-Yates 洗牌。每步交换都触发 Before/After Hook 并同步视觉；每轮后重新获取列表引用，防止其他操作改变引用。少于 2 张牌时直接返回。

移到边缘：MoveToEdges

public static async Task MoveToEdges(Player owner, CardModel card, bool toLeft)

从原位置移除 card 并插入到手牌最左（toLeft=true）或最右（toLeft=false）。触发 Before/After Hook 并同步视觉。卡不在手牌中时直接返回。
