UltraLib 新增 Utils（工具类）总表
UltraLib 在 Base/Utils 下提供了一系列静态工具类，封装 StS2 的常用操作， 让你不必重复实现或深入游戏私有 API。按你操作的对象选对应的 Helper。

工具类一览

工具类典型用途
CardHelper卡牌创建、克隆、消耗、升级/降级、关键词、自动打出、附魔、转化等（功能最全）。
CardListHelper从牌堆取牌、选择卡牌、按稀有度/费用筛选、打乱顺序。
CardPileHelper把卡加入牌堆、随机打乱牌堆、抽牌。
CreatureHelper动画触发、加格挡、造成伤害、加最大生命并回血、治疗。
PowerHelper施加/获取/移除能力、修改层数、获取能力悬浮提示。
OrbHelper生成充能球（Channel）、激发（Evoke）、修改数值、获取列表、移除槽位。
DiscoverHelper"发现"机制：从多个卡池随机展示若干卡牌供玩家选择。
RewardsHelper从当前奖励界面获取玩家的奖励数据（含卡牌奖励）。
RelicSelectionHelper从多个遗物中让玩家选择其一（支持联机同步）。
HandUiHelper手牌 UI 操作：交换、对齐视觉、洗牌、移动到边缘（逻辑层+UI 同步）。
HoverTipHelper刷新玩家的所有悬浮提示（商店 + 战斗卡牌）。
LocStringHelper把本地化字符串（LocString）解析为格式化文本。
AttackHelper构建 AttackCommand：设置攻击者、伤害属性、修改最终伤害、清除目标。
ActionQueueHelper把 GameAction 入队（优先同步器，单机回退反射）。
AncientEventHelper为远古事件创建遗物选项（反射调用）。
DynamicVarHelper动态变量通用操作（预留）。
如何使用一个工具类
工具类都是静态方法，直接按 类名.方法名 调用即可。例： 
// 消耗一张卡牌
await CardHelper.Exhaust(card);

// 给目标施加能力
await PowerHelper.Apply<StrengthPower>(ctx, target, 2m, applier, card);

// 从三个卡池"发现"一张卡
CardModel? picked = await DiscoverHelper.Discover(ctx, player, pools, cardPlay, null);

每个工具类的完整方法级说明见在线 Wiki 的 Utils Helper 页。
