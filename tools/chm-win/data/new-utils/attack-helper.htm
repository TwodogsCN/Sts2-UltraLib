AttackHelper AttackCommand 构建辅助工具
AttackCommand 是 StS2 的攻击命令构建器，其关键属性/字段是私有的。 本类通过反射提供链式修改方法：设置攻击者、伤害属性、修改最终伤害、清除目标。 所有方法都返回命令本身，便于链式调用。

方法总览

方法作用
SetAttacker设置攻击命令的发起者（Attacker）。
SetDamageProps设置攻击命令的伤害属性（整体替换）。
AddDamageProps追加伤害属性（按位或合并）。
ModifySingleFinalDamage修改单次最终伤害值（转换函数）。
ClearTargets清除攻击目标（单个目标、战斗状态、随机标志、目标侧）。

方法详解

设置攻击者：SetAttacker

public static AttackCommand SetAttacker(this AttackCommand cmd, Creature attacker)

通过反射设置 Attacker 属性为指定生物。返回命令本身。

设置伤害属性：SetDamageProps

public static AttackCommand SetDamageProps(this AttackCommand cmd, ValueProp prop)

整体替换 DamageProps 属性为 prop。返回命令本身。

追加伤害属性：AddDamageProps

public static AttackCommand AddDamageProps(this AttackCommand cmd, ValueProp prop)

读取当前 DamageProps 并按位或（|）合并 prop 后写回，用于给已有攻击追加属性（如追加「无视格挡」）。返回命令本身。

修改最终伤害：ModifySingleFinalDamage

public static AttackCommand ModifySingleFinalDamage(
    this AttackCommand cmd, Func<decimal, decimal> damageModifier)

用 damageModifier 转换函数修改最终伤害：若尚未计算最终伤害（基础伤害为负），则修改计算伤害变量的基础值；否则直接改 _damagePerHit 并清空缓存的计算变量。返回命令本身。适合实现「伤害 X 点加成/减半」类效果。

清除目标：ClearTargets

public static AttackCommand ClearTargets(this AttackCommand cmd)

清空单个目标字段、战斗状态、IsRandomlyTargeted 标志与 TargetSide（自动处理属性或后备字段）。反射出错时打印错误但不会中断。返回命令本身。
