DiscoverHelper 发现（Discover）机制辅助工具
类似炉石传说「发现」机制：从多个卡池中随机选取若干卡牌供玩家选择一张。 内部处理解锁卡牌过滤、筛选条件、去重随机、可选升级与跳过。

方法总览

方法作用
Discover从多个卡池随机展示 3 张卡牌供玩家选择。

方法详解

发现：Discover

public static async Task<CardModel?> Discover(
    PlayerChoiceContext choiceContext, Player player,
    List<CardPoolModel> cardPools, CardPlay? cardPlay,
    Func<CardModel, bool>? filter,
    bool isUpgrade = false, bool canSkip = false)

流程：① 从所有卡池收集玩家已解锁的卡牌 → ② 应用 filter 筛选 → ③ 用战斗 RNG 随机取 3 张去重卡 → ④ isUpgrade=true 时全部升级 → ⑤ 弹出三选一界面。

参数：choiceContext 玩家选择上下文；player 进行发现的玩家；cardPools 可选卡池列表；cardPlay 来源卡牌打出记录（可为 null）；filter 卡牌筛选条件（null 表示全部）；isUpgrade 是否升级展示的卡；canSkip 是否允许跳过。

返回：玩家选中的卡牌；跳过或卡池为空时返回 null。
