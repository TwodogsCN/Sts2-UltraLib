CardListHelper 卡牌列表操作辅助工具
提供从牌堆取牌、从手牌/列表/牌堆中选择卡牌、按稀有度/费用筛选、随机打乱等功能。 常用于实现「选择 X 张牌」「筛选符合条件的牌」等卡牌效果。

方法总览

方法作用
FromPile从玩家指定牌堆获取所有卡牌。
SelectCardFromHand（两种重载）从手牌中选择卡牌（排除源卡 / 带筛选条件）。
SelectCardFromList从任意卡牌列表中选择指定数量。
SelectCardFromPile（两种重载）从指定牌堆中选择卡牌（可选有序）。
Filter（稀有度 / 费用）按稀有度或能量费用筛选卡牌。
RandomizeOrder（生物 / RNG）打乱卡牌列表顺序。

方法详解

取牌：FromPile

public static List<CardModel> FromPile(Player owner, PileType pileType)

获取玩家指定牌堆（抽牌堆 / 弃牌堆 / 手牌 / 消耗堆等）中的所有卡牌副本列表。

从手牌选择：SelectCardFromHand（重载 1，排除源卡）

public static async Task<List<CardModel>> SelectCardFromHand(
    PlayerChoiceContext choiceContext, Player player, LocString prompt,
    int minCount, int maxCount, CardModel card)

从手牌中选择最少 minCount、最多 maxCount 张牌，并排除源卡牌 card（例如「弃掉除这张以外的手牌」）。prompt 为选择界面的提示文本。

从手牌选择：SelectCardFromHand（重载 2，带筛选）

public static async Task<List<CardModel>> SelectCardFromHand(
    PlayerChoiceContext choiceContext, Player player, LocString prompt,
    int count, Func<CardModel, bool>? filter, AbstractModel source)

从手牌中选择恰好 count 张符合 filter 条件的牌。筛选器传 null 表示不筛选；source 为效果来源模型（用于排除自身）。

从列表选择：SelectCardFromList

public static async Task<List<CardModel>> SelectCardFromList(
    PlayerChoiceContext choiceContext, IReadOnlyList<CardModel> cardsIn, Player player,
    LocString prompt, int minCount, int maxCount)

从任意给定的卡牌列表中弹出选择界面，让玩家选最少 minCount、最多 maxCount 张。适用于「从生成的若干张牌里选一张」等场景。

从牌堆选择：SelectCardFromPile（重载 1，固定数量）

public static async Task<List<CardModel>> SelectCardFromPile(
    PlayerChoiceContext choiceContext, Player player, PileType pile, LocString prompt,
    int count, CardModel? cardSource = null, bool isOrdered = false,
    Func<CardModel, bool>? filter = null)

从指定牌堆中选择恰好 count 张。isOrdered=true 时先按稀有度、再按 ID 排序展示；牌堆为空直接返回空列表。可用于「从弃牌堆回收 N 张牌」。

从牌堆选择：SelectCardFromPile（重载 2，数量范围）

public static async Task<List<CardModel>> SelectCardFromPile(
    PlayerChoiceContext choiceContext, Player player, PileType pile, LocString prompt,
    int minCount, int maxCount, CardModel? cardSource = null, bool isOrdered = false)

同上，但选择数量为范围 minCount ~ maxCount（玩家可少选）。

稀有度筛选：Filter

public static List<CardModel> Filter(CardRarity rarity, List<CardModel> cardList, int cmp = 0)

按稀有度筛选：cmp = 0 只取等于；cmp < 0 取「等于或更低稀有度」；cmp > 0 取「等于或更高稀有度」（如传入 Rare 且 cmp>0 等价于全部）。

费用筛选：Filter

public static List<CardModel> Filter(int energyCost, List<CardModel> cardList, int cmp = 0)

按解析后的能量费用筛选：cmp = 0 等于；cmp < 0 小于等于；cmp > 0 大于等于。

打乱顺序：RandomizeOrder（两种重载）

public static List<CardModel> RandomizeOrder(Creature creature, List<CardModel> cardList)
public static List<CardModel> RandomizeOrder(Rng rng, List<CardModel> cardList)

使用生物所属战斗的 RNG（第一个重载，战斗状态为空时原样返回）或指定 Rng（第二个重载）进行不稳定洗牌，返回新列表。用于「随机打乱可选卡牌顺序」。
