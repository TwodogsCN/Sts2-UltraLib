CreatureHelper 生物操作辅助工具
封装 CreatureCmd 的常用操作：动画触发、格挡、伤害、最大生命与治疗。 所有修改类方法走游戏命令系统（Cmd），保证联机同步与事件触发。

方法总览

方法作用
TriggerAnim触发生物的指定动画。
CastCardOnCreature触发玩家的施法动画。
GainBlock为生物增加格挡值（两种重载）。
Damage对目标造成伤害（单目标 / 多目标两种重载）。
GainMaxHpAndHeal增加最大生命值，可选回血。
Heal治疗生物。

方法详解

触发动画：TriggerAnim

public static async Task TriggerAnim(Creature creature, string triggerName, float waitTime)

触发 creature 上名为 triggerName 的动画，并等待 waitTime 秒。常用于自定义攻击/受击演出。

施法动画：CastCardOnCreature

public static async Task CastCardOnCreature(Player player)

对玩家生物触发 "Cast" 动画，等待时间取角色配置的 CastAnimDelay。打出一张自定卡牌前调用可还原原版手感。

加格挡（变量版）：GainBlock

public static async Task<decimal> GainBlock(Creature creature, BlockVar blockVar,
    CardPlay? cardPlay, bool fast = false)

使用 BlockVar（含基础值与属性标记 Props）为生物加格挡。返回实际获得的格挡值。

加格挡（数值版）：GainBlock

public static async Task<decimal> GainBlock(Creature creature, decimal amount,
    ValueProp props, CardPlay? cardPlay, bool fast = false)

直接指定格挡数值与属性标记。返回实际获得的格挡值。

造成伤害（单目标）：Damage

public static async Task<IEnumerable<DamageResult>> Damage(
    PlayerChoiceContext choiceContext, Creature target, decimal amount,
    ValueProp props, Creature? dealer, CardModel? cardSource, CardPlay? cardPlay)

对单个目标 target 造成 amount 点伤害，携带伤害属性 props。返回伤害结算结果列表（含格挡吸收、实际扣血等）。

造成伤害（多目标）：Damage

public static async Task<IEnumerable<DamageResult>> Damage(
    PlayerChoiceContext choiceContext, IEnumerable<Creature>? targets,
    DamageVar damageVar, Creature? dealer, CardModel? cardSource, CardPlay? cardPlay)

对目标列表造成伤害，数值与属性取自 DamageVar（含 BaseValue 与 Props）。适合 AOE 类效果。

增加最大生命：GainMaxHpAndHeal

public static async Task GainMaxHpAndHeal(Creature creature, decimal amount, bool isHeal = true)

增加 amount 点最大生命值；isHeal=true 时同时回复等量生命。会记录到地图点历史（MaxHpGained）。注意：amount 必须为非负数，否则抛出 ArgumentException（减少最大生命请用 LoseMaxHp 类方法）。

治疗：Heal

public static async Task Heal(Creature creature, decimal amount)

治疗生物 amount 点生命（不会超过最大生命值）。
