RewardHelper 奖励（Reward）界面辅助工具
获取当前奖励界面中指定玩家的奖励数据。 内部使用反射访问 NRewardsScreen 的私有字段，并按玩家身份过滤， 保证联机模式下每个玩家只拿到自己的奖励。

方法总览

方法作用
GetCurrentRewards获取指定玩家当前可见的全部 Reward 数据。
GetCurrentCardRewards获取指定玩家当前的卡牌奖励（CardReward）列表。

方法详解

获取当前奖励：GetCurrentRewards

public static List<Reward> GetCurrentRewards(Player player)

从当前顶层的 NRewardsScreen 读取奖励按钮列表，提取 NRewardButton.Reward，只保留 Reward.Player == player 的项。若玩家为 null、当前没有奖励界面、或屏幕与玩家不属于同一 RunState（多人安全校验），返回空列表。反射字段为惰性缓存，异常会被捕获并打印，不影响游戏运行。

获取卡牌奖励：GetCurrentCardRewards

public static List<CardReward> GetCurrentCardRewards(Player player)

在 GetCurrentRewards 结果中筛选出 CardReward 类型的子集。用于读取当前奖励界面上展示的卡牌奖励（例如做「跳过奖励自动重roll」类功能）。
