AncientEventHelper 远古事件（AncientEvent）辅助工具
通过反射调用 AncientEventModel 的私有 RelicOption 方法， 为指定遗物类型创建一个事件选项（EventOption）。

方法总览

方法作用
CreateRelicOption<T>为指定遗物类型创建事件选项。

方法详解

创建遗物选项：CreateRelicOption<T>

public static EventOption CreateRelicOption<T>(this AncientEventModel instance)
    where T : RelicModel

扩展方法，直接 ancientEvent.CreateRelicOption<MyRelic>() 调用。从 ModelDb.Relic<T>() 取蓝图并 ToMutable()，反射调用私有的 RelicOption(relic, "INITIAL", null) 返回事件选项。用于给自定义远古事件添加「获得某遗物」的选项。
