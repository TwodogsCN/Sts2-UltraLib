OrbHelper 充能球（Orb）辅助工具
提供充能球的生成（Channel）、激发（Evoke）、数值修改、列表获取与槽位管理。 其中激发走原版私有方法的反射调用，生成与槽位操作均带战斗状态保护。

方法总览

方法作用
Channel<T>为玩家生成一个指定类型的充能球。
NoAwaitChannel<T>安全地异步生成充能球（不阻塞调用方）。
EvokeOrb激发指定充能球（反射调用原版 Evoke）。
SetVal强制修改充能球的数值并同步 UI。
GetOrbList安全获取当前充能球列表的只读快照。
RemoveSlots移除充能球槽位（带战斗结束检查与 UI 动画）。

方法详解

生成充能球：Channel<T>

public static async Task<T?> Channel<T>(PlayerChoiceContext choiceContext, Player player)
    where T : OrbModel

从 ModelDb.Orb<T>() 取蓝图并 ToMutable()，随后调用 OrbCmd.Channel 为玩家生成充能球。蓝图不存在时打印错误并返回 null。

安全异步生成：NoAwaitChannel<T>

public static void NoAwaitChannel<T>(PlayerChoiceContext choiceContext, Player player)
    where T : OrbModel

fire-and-forget 版本：内部先 Task.Yield，仅当玩家存活时才生成；异常被捕获并打印。适合在不能 await 的回调（如 Hook）中安全地生成充能球。

激发充能球：EvokeOrb

public static async Task EvokeOrb(PlayerChoiceContext choiceContext, Player player,
    OrbModel targetOrb, bool dequeue = true)

通过反射调用原版 OrbCmd.Evoke 激发 targetOrb。dequeue=true 时该球会从队列移除。战斗已结束/正在结束时直接返回，不做任何操作。

强制设置数值：SetVal

public static void SetVal(OrbModel orb, decimal amount)

用 Harmony Traverse 直接写入充能球的 _passiveVal 字段，覆盖当前数值。用于「设定为固定值」类效果（例如把球的数值设为 X）。

获取充能球列表：GetOrbList

public static List<OrbModel> GetOrbList(Player player)

返回玩家当前充能球队列的副本快照（只读遍历安全）；玩家或队列为空时返回空列表。

移除槽位：RemoveSlots

public static void RemoveSlots(Player player, int amount)

从玩家身上移除 amount 个充能球槽位（不会低于 0），并播放槽位移除动画。战斗结束/正在结束时直接返回。
