HoverTipHelper 玩家悬停提示刷新辅助
一键刷新玩家的所有悬停提示：商店（Merchant）库存条目 + 战斗中的全部卡牌。

方法总览

方法作用
Refresh刷新玩家的所有悬停提示（商店 + 战斗卡牌）。

方法详解

刷新悬停提示：Refresh

public static void Refresh(this Player owner)

扩展方法，直接 player.Refresh() 调用。
若当前房间是 MerchantRoom，遍历所有库存条目调用 OnMerchantInventoryUpdated()；若玩家有战斗状态，遍历 AllCards 调用 RefreshHoverTips()。适合在修改了卡牌数值/关键词后强制刷新显示。
