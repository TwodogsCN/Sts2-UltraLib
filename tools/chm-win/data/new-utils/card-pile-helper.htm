CardPileHelper 牌堆操作辅助工具
封装 CardPileCmd 的常用操作：向牌堆加牌、随机打乱牌堆、抽牌。 注意：这里操作的是「牌堆」本身（抽牌堆、弃牌堆、手牌等），与单张卡牌操作（CardHelper）区分。

方法总览

方法作用
AddToPile把一张卡添加到指定牌堆的指定位置。
RandomizeOrderForPile使用游戏 RNG 随机打乱整个牌堆。
Draw从抽牌堆抽取指定数量的卡。

方法详解

添加卡牌：AddToPile

public static async Task<CardPileAddResult> AddToPile(
    CardModel card, PileType pile, CardPilePosition position)

把 card 添加到 pile 的指定位置（顶部 / 底部 / 随机）。返回 CardPileAddResult 描述添加结果。这是最底层的入堆操作，不带预览动画、不触发生成 Hook——需要预览请用 CardHelper.AddToPile。

打乱牌堆：RandomizeOrderForPile

public static void RandomizeOrderForPile(PileType cardPile, Player player)

对玩家 player 的 cardPile 牌堆调用内部 RandomizeOrderInternal，使用玩家运行状态的洗牌 RNG 打乱顺序。适用于「洗回牌堆并打乱」类效果。

抽牌：Draw

public static async Task<IEnumerable<CardModel>> Draw(
    PlayerChoiceContext choiceContext, decimal count, Player player,
    bool fromHandDraw = false)

从抽牌堆抽取 count 张牌到手上。数量支持小数（如 0.5 表示抽一张但概率减半）。fromHandDraw=true 表示「从手牌抽出（回收）」的特殊抽法。返回实际抽到的卡牌列表。
