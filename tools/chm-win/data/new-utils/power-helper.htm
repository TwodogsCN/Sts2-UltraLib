PowerHelper 能力（Power）辅助工具
封装能力（Power）的施加、获取、移除、层数修改与视觉刷新。 施加能力时通过泛型 Apply<T> 指定能力类型即可，UltraLib 自动从 ModelDb 取蓝图。

方法总览

方法作用
Apply<T>为单目标 / 多目标施加指定类型能力。
Apply用指定 PowerModel 实例施加能力（须为 Mutable）。
GetPowerTip获取能力的悬浮提示。
RefreshVisuals刷新能力拥有者的视觉显示（意图重算）。
GetPower<T>从生物身上获取指定类型的能力。
Remove移除并清理指定能力。
Decrement能力层数减 1。
ModifyAmount修改能力层数（正负偏移）。

方法详解

施加能力（单目标）：Apply<T>

public static async Task<T?> Apply<T>(
    PlayerChoiceContext choiceContext, Creature target, Decimal amount,
    Creature? applier, CardModel? cardSource, bool silent = false)
    where T : PowerModel

给目标 target 添加 T 类型能力，层数为 amount（允许小数）。silent=true 时不播放提示动画。返回施加成功的能力实例。

施加能力（多目标）：Apply<T>

public static async Task<IReadOnlyList<T>> Apply<T>(
    PlayerChoiceContext choiceContext, IEnumerable<Creature> targets, Decimal amount,
    Creature? applier, CardModel? cardSource, bool silent = false)
    where T : PowerModel

给一组目标 targets 同时施加能力，参数含义同上。返回施加结果列表。

施加能力（实例版）：Apply

public static async Task Apply(
    PlayerChoiceContext choiceContext, PowerModel power, Creature target,
    Decimal amount, Creature? applier, CardModel? cardSource, bool silent = false)

使用已经构造好的 power 实例施加能力。注意：实例必须来自 ToMutable()，否则原版命令会拒绝。适用于需要自定义能力属性的场景。

获取能力悬浮提示：GetPowerTip

public static IHoverTip? GetPowerTip(PowerModel power)

通过反射调用 HoverTipFactory.FromPower 获取该能力类型的悬浮提示，用于自绘 UI 或调试。失败返回 null。

刷新能力视觉：RefreshVisuals

public static void RefreshVisuals(this PowerModel power)

让能力拥有者所在的战斗房间节点重新计算意图（RefreshIntents）。能力数值被外部直接修改后调用，可刷新敌人头顶的意图显示。

获取能力：GetPower<T>

public static T? GetPower<T>(Creature creature) where T : PowerModel

从生物 creature 身上获取 T 类型能力，不存在返回 null。例如判断敌人是否有 StrengthPower。

移除能力：Remove

public static async Task Remove(PowerModel? power)

移除并清理指定能力：先调用 RemoveInternal，等待 0.2~0.4 秒演出，再调用 AfterRemoved 完成善后。传入 null 直接返回。

层数减一：Decrement

public static async Task Decrement(PowerModel power)

等价于 ModifyAmount(..., -1, null, null)，层数减 1。

修改层数：ModifyAmount

public static async Task<int> ModifyAmount(
    PlayerChoiceContext choiceContext, PowerModel power, Decimal offset,
    Creature? applier, CardModel? cardSource, bool silent = false)

将能力层数加上 offset（可为负）。返回修改后的层数。修改层数（如力量、易伤）请走这里，而不是直接改字段。
