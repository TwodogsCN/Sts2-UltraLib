CardExporter 卡牌渲染导出工具
把卡牌模型渲染为 PNG 图片保存到磁盘，用于导出卡牌素材和文档预览。 注意：这是 Node 子类（partial class），但两个方法都是静态的， 直接 CardExporter.RenderCardToImage(...) 调用即可；渲染依赖场景树，需在游戏运行中调用。

方法总览

方法作用
RenderCardToImage生成单张卡牌图像并保存（默认 512×512 视口，自动裁剪）。
RenderCardWithHoverTipsToImage生成带悬浮提示的卡牌图像并保存（默认 2560×1440 视口）。

方法详解

渲染卡牌：RenderCardToImage

public static async Task<Error> RenderCardToImage(CardModel cardModel, string savePath = "")

流程：① savePath 为空时使用 user://{Title}.png（建议传带卡牌 ID 的路径，避免特殊字符保存失败）；② 挂到 NCombatRoom 或 NGame 下创建 512×512 透明 SubViewport；③ 实例化 NCard，移除「不可打出能量图标」，以 Hand/Normal 模式刷新视觉；④ 等待 150ms + 10 帧（让异步加载与本地化完成）；⑤ 抓图、按内容自动裁剪（外扩 10px）后 SavePng。

返回：Error 保存结果；渲染失败返回 Error.Failed。

渲染带悬浮提示：RenderCardWithHoverTipsToImage

public static async Task<Error> RenderCardWithHoverTipsToImage(
    CardModel cardModel, string savePath = "")

流程：在 2560×1440 透明视口中横向布局：左侧卡牌（270×460），右侧悬浮提示列表——普通 HoverTip 词条（标题/描述/图标，Debuff 带红色材质）与 CardHoverTip 衍生卡（220×320 迷你卡）分列展示。等待 400ms + 35 帧后抓图，按内容裁剪（外扩 90px）保存。

返回：Error 保存结果；渲染失败返回 Error.Failed。
