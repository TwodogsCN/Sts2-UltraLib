CardHelper 卡牌操作辅助工具
封装 CardCmd / CardPileCmd 的常用操作，是功能最全的卡牌工具类。 覆盖：生成/添加卡牌、预览、消耗、弃牌、升级/降级、关键词、动态变量（返回/赋能）、 克隆、创建、自动打出、转变、附魔、锻造预览等。

方法总览

方法作用
PreviewAddGeneratedCardToCombat生成一张卡加入战斗并显示预览动画。
PreviewCardPileAddResult播放一次牌堆添加结果的预览动画。
Exhaust（单张 / 列表）消耗一张或一组卡牌。
Upgrade / Downgrade（单张 / 列表）升级 / 降级卡牌。
AddGeneratedCardToCombat生成卡牌进入战斗，触发生成卡 Hook，返回添加结果。
AddToPile（单张 / 列表）把卡加入牌堆（可带预览，不触发生成 Hook）。
GetModelDb获取卡牌对应的原版（canonical）模型。
Clone / CloneOrigin克隆卡牌 / 克隆原版版本的卡牌。
ApplyKeyword / RemoveKeyword（单张 / 列表）添加 / 移除卡牌关键词。
AddReturnVar / RemoveReturnVar添加 / 移除卡牌「返回」效果变量。
AddEmpowerVar / RemoveEmpowerVar添加 / 移除卡牌「赋能」效果变量。
RefreshHoverTips刷新卡牌的悬浮提示（触发原版视觉更新）。
AutoPlay（两种重载）自动打出一张卡牌（自动选择目标）。
GetAutoTarget获取一张卡牌可指定的随机目标。
SetCardType设置卡牌类型（反射写入 Type）。
Discard（单张 / 列表）弃掉一张或一组卡牌。
Preview预览一张卡（出现在中央再飞回牌堆）。

CreateCard（泛型 / 基于原版）创建一张卡牌。
TransformTo / Transform / PreviewTransform把一张卡转变为另一张卡（可带预览）。
PreviewSovereignBlade（单张 / 集合）播放「锻造」样式的卡牌预览特效。

方法详解

生成 + 预览：PreviewAddGeneratedCardToCombat

public static async Task PreviewAddGeneratedCardToCombat(
    CardModel card, PileType pile, Player? player,
    CardPilePosition position,
    CardPreviewStyle style = CardPreviewStyle.HorizontalLayout)

生成一张卡加入指定牌堆，并立即播放添加预览动画。内部先调用 AddGeneratedCardToCombat 再调用 PreviewCardPileAdd。

预览：PreviewCardPileAddResult

public static void PreviewCardPileAddResult(CardPileAddResult result)

对一个已有的牌堆添加结果播放预览动画（卡从中央飞向目标牌堆）。

消耗：Exhaust（两种重载）

public static async Task Exhaust(List<CardModel> cardList, PlayerChoiceContext? playerChoiceContext = null)
public static async Task Exhaust(CardModel card, PlayerChoiceContext? playerChoiceContext = null)

消耗一张或一组卡牌。未传入选择上下文时自动使用 BlockingPlayerChoiceContext（阻塞等待玩家选择）。

升级 / 降级：Upgrade / Downgrade（各两种重载）

public static void Upgrade(CardModel card)          // 升级单张
public static void Upgrade(List<CardModel> cardList) // 升级一组
public static void Downgrade(CardModel card)          // 降级单张
public static void Downgrade(List<CardModel> cardList) // 降级一组

调用 CardCmd.Upgrade / CardCmd.Downgrade 批量修改卡牌升级状态。列表重载会逐个处理。

生成入战斗：AddGeneratedCardToCombat

public static async Task<CardPileAddResult> AddGeneratedCardToCombat(
    CardModel card, PileType pile, Player? player,
    CardPilePosition position,
    CardPreviewStyle style = CardPreviewStyle.HorizontalLayout)

生成一张卡加入战斗（触发游戏的「生成卡牌」Hook），返回 CardPileAddResult 供后续处理。

加入牌堆：AddToPile（两种重载）

public static async Task AddToPile(CardModel card, PileType pile, CardPilePosition position,
    bool isPreview = true, CardPreviewStyle style = CardPreviewStyle.HorizontalLayout)
public static async Task AddToPile(List<CardModel> cardList, PileType pile, CardPilePosition position,
    bool isPreview = true, CardPreviewStyle style = CardPreviewStyle.HorizontalLayout)

把卡加入指定牌堆指定位置。默认带预览动画；isPreview=false 时静默加入。注意：不触发「生成卡牌」Hook。

原版模型：GetModelDb

public static CardModel GetModelDb(CardModel cardModel)

按传入卡牌的实际类型从 ModelDb 中取回原版（canonical）模型。返回的是共享蓝图，如需修改应先 ToMutable()。

克隆：Clone / CloneOrigin

public static CardModel Clone(CardModel cardModel)
public static CardModel CloneOrigin(CardModel cardModel, Player player, ICombatState combatState)

Clone 直接复制一张卡（保留当前升级等状态）；CloneOrigin 先取原版模型再创建，得到该卡「最初版本」的复制卡。

关键词：ApplyKeyword / RemoveKeyword（各两种重载）

public static void ApplyKeyword(CardModel card, params CardKeyword[] keywordsList)
public static void ApplyKeyword(List<CardModel> cardList, params CardKeyword[] keywordsList)
public static void RemoveKeyword(CardModel card, params CardKeyword[] keywordsList)
public static void RemoveKeyword(List<CardModel> cardList, params CardKeyword[] keywordsList)

批量给卡牌添加 / 移除关键词（如 固有、消耗、虚无 等）。参数用 params，可一次传多个。

动态变量（返回）：AddReturnVar / RemoveReturnVar

public static void AddReturnVar(this CardModel card, decimal value)
public static bool RemoveReturnVar(this CardModel card)

给卡牌添加「返回」效果变量（用于打出手牌返回类效果）。若已存在则累加数值；添加后自动刷新悬浮提示。移除返回变量成功返回 true。

动态变量（赋能）：AddEmpowerVar / RemoveEmpowerVar

public static void AddEmpowerVar(this CardModel card, PowerModel power, decimal value)
public static bool RemoveEmpowerVar(this CardModel card)

给卡牌添加「赋能」效果变量（绑定一个能力对象和数值）。移除赋能变量成功返回 true。

刷新悬浮提示：RefreshHoverTips

public static void RefreshHoverTips(this CardModel card)

查找卡牌对应的场景节点，以当前牌堆类型调用原版 UpdateVisuals，触发 HoverTips 重新读取。在修改卡牌动态变量后调用以同步显示。

自动打出：AutoPlay（两种重载）

public static async Task AutoPlay(PlayerChoiceContext choiceContext, CardModel card, ICombatState combatState, bool skipX = true)
public static async Task AutoPlay(CardModel card, ICombatState combatState, bool skipX = true)

自动打出一张卡牌：自动选择目标（GetAutoTarget），可跳过 X 费用询问。第二个重载不要求传上下文（内部用 BlockingPlayerChoiceContext）。

自动目标：GetAutoTarget

public static Creature? GetAutoTarget(CardModel card, ICombatState combatState)

按卡牌目标类型返回一个合适目标：任意敌人取第一个可打击敌人；任意友军用 RNG 随机选存活友军；任意玩家取自己；全体目标返回 null（不指定单目标）。

设置卡牌类型：SetCardType

public static void SetCardType(this CardModel card, CardType newType)

通过 Harmony Traverse 写入卡牌的 <Type>k__BackingField，修改卡牌类型（攻击 / 技能 / 能力）。

弃牌：Discard（两种重载）

public static async Task Discard(PlayerChoiceContext choiceContext, IEnumerable<CardModel> card)
public static async Task Discard(PlayerChoiceContext choiceContext, CardModel card)

弃掉一张或一组卡牌。需要传入有效的选择上下文。

预览：Preview

public static TaskCompletionSource? Preview(CardModel card, float time = 1.2f, CardPreviewStyle style = CardPreviewStyle.HorizontalLayout)

让卡牌出现在屏幕中央再飞回原牌堆。返回的 TaskCompletionSource 可在动画结束时收到完成信号（可为 null）。

附魔：Enchant（两种重载）

public static T? Enchant<T>(CardModel card, Decimal amount) where T : EnchantmentModel
public static EnchantmentModel? Enchant(EnchantmentModel enchantment, CardModel card, Decimal amount)

给卡牌添加指定量的附魔。泛型版本按附魔类型从 ModelDb 取蓝图；实例版本使用传入的附魔实例（会自动 ToMutable）。返回添加的附魔实例。

创建卡牌：CreateCard（两种重载）

public static T CreateCard<T>(ICombatState combatState, Player player) where T : CardModel
public static CardModel CreateCard(CardModel canonicalCard, ICombatState combatState, Player player)

泛型版本从 ModelDb 取蓝图创建；实例版本以给定原版卡为基础创建。二者都归属指定玩家并绑定战斗状态。

转变：TransformTo / Transform / PreviewTransform

public static async Task<CardPileAddResult?> TransformTo<T>(CardModel card) where T : CardModel
public static async Task<CardPileAddResult?> Transform(CardModel original, CardModel replacement, CardPreviewStyle style = CardPreviewStyle.HorizontalLayout)
public static async Task PreviewTransform(CardModel original, CardModel replacement, CardPreviewStyle style = CardPreviewStyle.HorizontalLayout)

TransformTo 把卡变成指定类型的原版版本；Transform 把一张卡变成另一张卡；PreviewTransform 额外带预览动画。均返回转变后的添加结果（可为 null）。

锻造预览：PreviewSovereignBlade（两种重载）

public static void PreviewSovereignBlade(IReadOnlyCollection<CardModel> cards)
public static void PreviewSovereignBlade(CardModel card)

播放「锻造」样式的预览特效。手牌中的卡在头顶播放特效，非手牌卡在中央预览容器播放；测试模式或非本人卡牌时自动跳过。
