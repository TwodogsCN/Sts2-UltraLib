LocStringHelper 本地化字符串辅助工具
LocString 是 StS2 的本地化字符串类型，可包含格式化占位符。 本类提供将其解析为最终展示文本的便捷方法。

方法总览

方法作用
ToFormattedString把 LocString 解析为格式化后的纯文本。

方法详解

解析为文本：ToFormattedString

public static string ToFormattedString(LocString locString)
    => locString.GetFormattedText();

调用原版 GetFormattedText() 返回格式化后的纯文本字符串。例如拿 LocString 类型的卡牌描述拼接到自己的日志或 UI 文本中时使用。
