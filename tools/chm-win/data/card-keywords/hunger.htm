Hunger 饥饿（卡牌关键词）
饥饿——使用后不可再次使用，除非有非爪牙敌方单位死亡。 显示在卡牌名称之前。

效果说明

拥有 Hunger 关键词的卡牌使用一次后进入"饥饿"状态，无法再次打出； 只有当非爪牙（non-minion）敌方单位死亡时才解除限制，恢复可用。 适合做「喂食/猎杀」主题的机制。

使用方式

// 给卡牌添加「饥饿」关键词
CardHelper.ApplyKeyword(card, PlusCardKeyWord.Hunger);

// 移除
CardHelper.RemoveKeyword(card, PlusCardKeyWord.Hunger);

定义位置：Base/Label/Card/PlusCardKeyWord.cs，关键词位置属性 AutoKeywordPosition.Before。
