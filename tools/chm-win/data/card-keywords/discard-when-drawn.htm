DiscardWhenDrawn 抽牌时丢弃（卡牌关键词）
抽牌时丢弃——当抽到带有此关键词的卡牌时，自动将其丢弃。 显示在卡牌名称之后。

效果说明

拥有 DiscardWhenDrawn 关键词的卡牌在被抽到时立即进入弃牌堆， 不进入手牌（不占手牌位）。可用于「诅咒/减益」类或「抽到即弃触发弃牌收益」的机制设计。

使用方式

// 给卡牌添加「抽牌时丢弃」关键词
CardHelper.ApplyKeyword(card, PlusCardKeyWord.DiscardWhenDrawn);

// 移除
CardHelper.RemoveKeyword(card, PlusCardKeyWord.DiscardWhenDrawn);

定义位置：Base/Label/Card/PlusCardKeyWord.cs，关键词位置属性 AutoKeywordPosition.After。
