CastWhenDrawn 抽牌时施放（卡牌关键词）
抽牌时施放——当抽到带有此关键词的卡牌时，自动将其打出。 显示在卡牌名称之前。

效果说明

拥有 CastWhenDrawn 关键词的卡牌在被抽到时立即自动打出（无需消耗费用/选择）。 该机制由 CastWhenDrawnSingleton 底层实现，并配套 Plus_BeforeCastWhenDrawn / Plus_AfterCastWhenDrawn 钩子。

使用方式

// 给卡牌添加「抽牌时施放」关键词
CardHelper.ApplyKeyword(card, PlusCardKeyWord.CastWhenDrawn);

// 移除
CardHelper.RemoveKeyword(card, PlusCardKeyWord.CastWhenDrawn);

定义位置：Base/Label/Card/PlusCardKeyWord.cs，关键词位置属性 AutoKeywordPosition.Before。
