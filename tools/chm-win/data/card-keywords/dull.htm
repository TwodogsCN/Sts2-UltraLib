Dull 迟钝（卡牌关键词）
迟钝——该牌在你的回合无法被丢弃。 显示在卡牌名称之前。

效果说明

拥有 Dull 关键词的卡牌在玩家回合内不能被手动丢弃， 防止因弃牌类效果而意外离手（回合结束自动弃牌等原版规则不受影响）。

使用方式

// 给卡牌添加「迟钝」关键词
CardHelper.ApplyKeyword(card, PlusCardKeyWord.Dull);

// 移除
CardHelper.RemoveKeyword(card, PlusCardKeyWord.Dull);

定义位置：Base/Label/Card/PlusCardKeyWord.cs，关键词位置属性 AutoKeywordPosition.Before。
