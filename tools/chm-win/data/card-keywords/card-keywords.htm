卡牌关键词（Card Keyword）
UltraLib 在 Base/Label/Card 的 PlusCardKeyWord 中定义了自定义卡牌关键词。 每个关键词通过 CustomEnumAttribute 注册到本地化系统， 并用 KeywordPropertiesAttribute 控制其在卡牌描述中的位置（名称前 Before / 名称后 After）。 给卡牌添加/移除关键词直接用 CardHelper.ApplyKeyword / RemoveKeyword。

关键词一览（一个文件一个词）

关键词位置作用
Isomorphism 同构名称后手牌中两张此词卡间隔一张时，自动打出中间那张。
CastWhenDrawn 抽牌时施放名称前抽到带此词的卡时自动打出。
Dull 迟钝名称前该牌在你的回合无法被丢弃。
Hunger 饥饿名称前使用后不可再次使用，除非有非爪牙敌方单位死亡。
InTest 测试中名称后标记仍在测试阶段的卡牌。
DiscardWhenDrawn 抽牌时丢弃名称后抽到带此词的卡时自动丢弃。
// 给卡牌添加「同构」关键词
CardHelper.ApplyKeyword(card, PlusCardKeyWord.Isomorphism);

// 移除「抽牌时丢弃」
CardHelper.RemoveKeyword(card, PlusCardKeyWord.DiscardWhenDrawn);
