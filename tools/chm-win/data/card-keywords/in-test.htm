InTest 测试中（卡牌关键词）
测试中——标记仍在测试阶段的卡牌。 显示在卡牌名称之后。

效果说明

拥有 InTest 关键词的卡牌仅作为开发标记， 提示制作者（和测试玩家）该卡尚未完成平衡或仍处于测试阶段， 方便在卡牌描述中直观区分正式卡与测试卡。

使用方式

// 给卡牌添加「测试中」关键词
CardHelper.ApplyKeyword(card, PlusCardKeyWord.InTest);

// 移除
CardHelper.RemoveKeyword(card, PlusCardKeyWord.InTest);

定义位置：Base/Label/Card/PlusCardKeyWord.cs，关键词位置属性 AutoKeywordPosition.After。
