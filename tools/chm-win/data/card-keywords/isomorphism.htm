Isomorphism 同构（卡牌关键词）
同构——当手牌中存在两张带有此关键词的卡牌间隔一张时， 自动打出中间的那张卡牌。显示在卡牌名称之后。

效果说明

拥有 Isomorphism 关键词的卡牌用于构建「同构」连锁： 如果手牌中两张带此词的卡中间恰好隔着一张其他卡，则中间那张会被自动打出。 该机制由 IsomorphismSingleton 底层实现，并配套 Plus_BeforeIsomorphism / Plus_AfterIsomorphism 钩子。

使用方式

// 给卡牌添加「同构」关键词
CardHelper.ApplyKeyword(card, PlusCardKeyWord.Isomorphism);

// 移除
CardHelper.RemoveKeyword(card, PlusCardKeyWord.Isomorphism);

定义位置：Base/Label/Card/PlusCardKeyWord.cs，关键词位置属性 AutoKeywordPosition.After。
