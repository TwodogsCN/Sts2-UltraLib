UltraLib 新增 Hooks（钩子）总表
UltraLib 的钩子系统以 IPlusHooks 为契约、PlusHooks 为分发器。 你的内容模型（遗物 / 能力 / 单例）只要实现 IPlusHooks（或继承 Plus* 基类）， 就会被自动收集并收到这些钩子调用。所有钩子都有默认实现，你只需覆写关心的部分。

一、事件钩子（Task，响应"发生了某事"）

钩子方法触发时机用途示例
Plus_AfterRandomRoomRolled(RoomType)随机房间 Roll 完成后根据房间类型调整地图逻辑
Plus_AfterHandPileMoved(CardModel)手牌堆移动后响应卡牌进/出手牌（同构检测依赖）
Plus_BeforeHandPileMoved(CardModel)手牌堆移动前在移动生效前阻止/修改
Plus_PowerRightClick(PowerModel, NPower)能力被右键点击自定义能力右键行为
Plus_RelicRightClick(RelicModel, holder)遗物被右键点击充能遗物右键触发
Plus_AfterRelicObtain(...) / Plus_BeforeRelicObtain(...)获得遗物后 / 前遗物获得逻辑
Plus_CardRightClick(CardModel, NCardHolder)卡牌被右键点击自定义卡牌右键
Plus_AfterChargeSpend(...) / Plus_AfterChargeGain(...)充能消耗/获得后充能变化后置逻辑
Plus_OnChargeFullyCharged(...) / Plus_OnChargeNoLongerFullyCharged(...)充能充满 / 不再充满充满触发效果
Plus_OnChargeChanged(old, new, ...)充能数值变化充能变化监测
Plus_BeforeChargeEffected(...) / Plus_AfterChargeEffected(...)
Plus_BeforeChargeTotallyEffected(...) / Plus_AfterChargeTotallyEffected(...)		充能效果生效前/后充能效果全流程
Plus_AfterOrbEvokeRemoved(...) / Plus_BeforeOrbEvoke(...)充能球激发后/前充能球激发流程
Plus_BeforeOrbPassive(...) / Plus_AfterOrbPassive(...)充能球被动生效前/后充能球被动流程
Plus_BeforeIsomorphism(...) / Plus_AfterIsomorphism(...)同构自动打牌前/后同构关键词流程
Plus_BeforeCastWhenDrawn(...) / Plus_AfterCastWhenDrawn(...)抽牌时施放前/后CastWhenDrawn 关键词流程
Plus_BeforeCardReturn(...) / Plus_AfterCardReturn(...)卡牌返回前/后Return 关键词流程
Plus_BeforeCardEmpower(...) / Plus_AfterCardEmpower(...)赋能前/后Empower 关键词流程

二、数值修改钩子（decimal，修改"某一个数值"）

对每个可修改值 X，有三个钩子：管线（Pipeline）、乘算（Multiplicative）、加算（Addictive）。 组合方式：Modify( (amount + Addictive) × Multiplicative )。
数值三个钩子说明
金币获得Plus_ModifyGoldGain / ...Multiplicative / ...Addictive修改金币获得量
金币损失Plus_ModifyGoldLoss / ...Multiplicative / ...Addictive修改金币损失量
最大充能Plus_ModifyMaxCharge / ...Multiplicative / ...Addictive修改遗物最大充能
充能升级量Plus_ModifyChargeUpgrade / ...Multiplicative / ...Addictive修改充能升级量
充能消耗量Plus_ModifyChargeSpend / ...Multiplicative / ...Addictive修改充能消耗量
充能重复次数Plus_ModifyChargeRepeatTimes / ...Multiplicative / ...Addictive修改充能效果重复次数
玫瑰数值Plus_ModifyRoseCard / ...Multiplicative / ...Addictive修改玫瑰类卡牌数值
如何实现一个钩子
继承 PlusRelicModel / PlusPowerModel / PlusSingletonModel， 然后覆写你需要的钩子方法即可，例如： 
public class MyRelic : PlusRelicModel
{
    // 玩家获得金币后触发——减半
    public override decimal Plus_ModifyGoldGain(decimal amount, Player player, bool wasStolenBack)
        => amount * 0.5m;
}

完整钩子分类与组合规则见在线 Wiki 的 Hook System 页。
