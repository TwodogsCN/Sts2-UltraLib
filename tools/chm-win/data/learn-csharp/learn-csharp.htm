简单认识 C#（写给模组制作者）
写 StS2 模组使用的语言是 C#。你不需要成为 C# 专家， 掌握下面几个基础概念就足够开始写模组了。

1. 类（Class）

类是一段可复用的代码模板。一个模组里的卡牌、遗物、能力，本质上都是一个类。 
public class MyCard : CardModel
{
    // 类的内容（成员、方法）
}

2. 继承（Inheritance）

继承 让一个新类"继承"已有类的能力，并可以覆盖（override）它的行为。 在 UltraLib 里，你通常会继承 PlusRelicModel、CardModel 这类基类。 
public class MyRelic : PlusRelicModel
{
    public override decimal Plus_ModifyGoldGain(decimal amount, Player player, bool stolenBack)
        => amount * 0.5m;
}

3. 方法（Method）

方法是被命名的代码块，可接收参数并返回结果。模组里常用的方法是 OnPlay（打出卡牌时）、 OnObtain（获得遗物时）等。 
public int Add(int a, int b)
{
    return a + b;
}

4. 命名空间（Namespace）

命名空间用于组织代码，避免重名。UltraLib 的代码都在 UltraLib 命名空间下， 例如 UltraLib.Base.Utils、UltraLib.Hook。

5. 关于 async / await

StS2 的很多 API 是异步的（返回 Task），用 await 等待完成。 你会在很多方法里看到 async / await， 只需要按模板写即可，不必深入原理。 
public async Task DoSomething()
{
    await CardCmd.Exhaust(ctx, card);
}

更深入的 C# 知识请参考微软官方文档。这里只列出写模组最常用的部分。
