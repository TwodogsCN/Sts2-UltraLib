UltraLib 新增功能专项
UltraLib 相对 BaseLib / 原版新增了三类核心能力： ① 钩子系统（Hooks）、② 工具类（Utils）、③ 充能遗物（Charge Relic）。 本页是这三类能力的总览入口，点击各卡片进入对应专项文档。

新增功能一览

① 钩子系统（Hooks） — 新 Hooks 表 →

以 IPlusHooks 为契约、PlusHooks 为分发器的扩展系统。 你的内容模型（遗物 / 能力 / 单例）实现 IPlusHooks（或继承 Plus* 基类）即可被自动收集。

  • 事件钩子：响应「发生了什么」——遗物右键、充能变化、充能球激发、手牌移动、卡牌返回/赋能等。
  • 数值修改钩子：修改「某个数值」——金币获得/损失、最大充能、充能升级量、充能消耗量、充能重复次数、玫瑰数值，采用 Pipeline / Multiplicative / Addictive 三段式组合。

② 工具类（Utils） — 新 Utils 表 →

Base/Utils 下提供 17 个静态工具类，封装 StS2 常用操作，避免重复实现或深入游戏私有 API。

  • 卡牌：CardHelper / CardListHelper / CardPileHelper / CardExporter
  • 战斗：CreatureHelper / AttackHelper / PowerHelper / OrbHelper
  • 机制：DiscoverHelper / RewardHelper / RelicSelectionHelper / AncientEventHelper
  • UI / 文本：HandUiHelper / HoverTipHelper / LocStringHelper / DynamicVarHelper
  • 队列：ActionQueueHelper

③ 充能遗物（Charge Relic） — 充能遗物总览 →

PlusChargeRelic 抽象基类：遗物有「当前充能 / 最大充能」，充能会回复（默认每房间 +1，可自定义）， 满充后触发效果并消耗充能。

  • 触发方式不写死：右键、自动、回合开始等由创作者自行决定。
  • 效果逻辑统一写在 MainEffect，由 DoChargeRelicEffect 执行，触发次数 Hook 自动生效。
  • 充能条 UI：自动在遗物图标下方渲染充能进度条。
  • 子页面：充能机制详解 · 触发与 Hook

三类能力分别有独立专项页；本页仅作总览。完整 API 地图见在线 Wiki 的 API 索引。
