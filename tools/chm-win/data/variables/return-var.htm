ReturnVar 返回（动态变量）
使卡牌在每回合前 N 次打出时返回手牌，而非进入弃牌堆。 动态变量键名：Return（ReturnVar.Key）。

是什么

ReturnVar 是 UltraLib 提供的返回动态变量（位于 UltraLib.Variables，继承 DynamicVar）。 实现类似「返回」关键词的效果：每回合有 N 次「打出后回手」的机会，次数随本回合打出次数递减。

核心成员

成员说明
Key动态变量键名常量，值 "Return"。
ReturnCount(card, basePersist)静态方法：计算当前剩余返回次数 = 基础次数 − 本回合已打出次数（最少 0）。

如何创建 / 使用

推荐直接用 CardHelper.AddReturnVar / RemoveReturnVar 操作卡牌：

// 给卡牌添加「返回」：每回合前 2 次打出后返回手牌
CardHelper.AddReturnVar(card, 2m);

// 移除返回
bool removed = CardHelper.RemoveReturnVar(card);

也可以直接构造

var returnVar = new ReturnVar(2m);
card.DynamicVars.Set(ReturnVar.Key, returnVar);

计数逻辑

ReturnCount(card, basePersist) 会统计本回合已完成打出的该卡牌次数 （从战斗历史的 CardPlaysFinished 中筛选），剩余次数 = 基础次数 − 已打出次数，最少为 0。 卡牌预览（UpdateCardPreview）显示的是当前剩余次数。
