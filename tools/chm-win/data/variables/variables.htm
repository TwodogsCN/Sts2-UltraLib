动态变量（DynamicVar）
UltraLib 在 Variables 目录下提供自定义动态变量。 动态变量挂在 CardModel.DynamicVars 上，用于在卡牌描述中渲染动态数值， 并可配合 CardHelper 便捷操作。当前提供两个词条（一个文件一个词）。

词条一览

词条键名作用
EmpowerVar 赋能Empower为卡牌注入指定能力，打出时使目标获得该能力若干层。
ReturnVar 返回Return每回合前 N 次打出后返回手牌，而非进入弃牌堆。

这两个动态变量的添加/移除均可直接使用 CardHelper.AddEmpowerVar / AddReturnVar 等便捷方法。
