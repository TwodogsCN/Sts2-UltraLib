EmpowerVar 赋能（动态变量）
为卡牌注入指定的能力（Power），在打出时使目标获得该能力的若干层数。 动态变量键名：Empower（EmpowerVar.Key）。

是什么

EmpowerVar 是 UltraLib 提供的赋能动态变量（位于 UltraLib.Variables，继承 DynamicVar）。 把「打出此牌时给目标上某个能力 X 层」封装成一个动态变量挂在卡牌上， 卡牌描述中会按 N 能力名 的形式自动渲染。

核心成员

成员说明
Key动态变量键名常量，值 "Empower"。
Power要赋予目标的能力模型（构造时必传，null 抛 ArgumentNullException）。
PowerCount能力层数（即 IntValue）。

如何创建 / 使用

推荐直接用 CardHelper.AddEmpowerVar / RemoveEmpowerVar 操作卡牌：

// 给卡牌添加「赋能」：打出时目标获得 3 层 力量（StrengthPower）
PowerModel strength = ModelDb.Power<StrengthPower>().ToMutable();
CardHelper.AddEmpowerVar(card, strength, 3m);

// 移除赋能
bool removed = CardHelper.RemoveEmpowerVar(card);

也可以直接构造

var empowerVar = new EmpowerVar(strength, 3m);
card.DynamicVars.Set(EmpowerVar.Key, empowerVar);

显示效果

ToString() 输出「3 力量」样式；能力为 null 时显示「X [能力]」占位。 构造时自动启用 Tooltip，悬浮提示可显示动态值。
