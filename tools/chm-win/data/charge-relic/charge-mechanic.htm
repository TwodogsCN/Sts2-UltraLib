新功能 [充能遗物] — 充能机制详解
这一页讲清楚充能遗物的「充能」是怎么来的、怎么消耗的、怎么设置的，以及默认逻辑如何修改。 核心成员全部位于 PlusChargeRelic（Base/Abstract/PlusChargeRelic.cs）。

核心成员

成员类型说明
NowCharge[SavedProperty] int当前充能数。设值时自动钳制 ≥ 0，并根据是否满充切换 RelicStatus。
TotalCharge[SavedProperty] int最大充能数（满充所需值）。设值时自动钳制 ≥ 0。
IsFullyChargedprotected bool是否已满充：NowCharge >= TotalCharge。
AutoChargevirtual bool（默认 true）是否在进入房间时自动充能。
UseChargeBarDisplayvirtual bool（默认 true）是否使用充能进度条 UI（false 则用数字显示）。
DisplayAmountoverride遗物角标显示的数字，即当前充能。
ShowCounteroverride（true）是否显示充能计数。

默认充能回复逻辑

默认情况下（AutoCharge == true），基类覆写了 AfterRoomEntered： 每次进入任意房间时自动调用一次 NowChargeUpgrade()（默认 +1 充能）。 也就是说，遗物每过一个房间就回复 1 点充能。 

// 基类默认行为（PlusChargeRelic.AfterRoomEntered）
public override Task AfterRoomEntered(AbstractRoom room)
{
    NowCharge = _nowCharge;      // 同步存档值
    if (AutoCharge)
        NowChargeUpgrade();  // 充能 +1
    return Task.CompletedTask;
}

不用默认逻辑：自定义充能回复

如果你的遗物不想「每房间 +1」，把 AutoCharge 覆写为 false， 然后在合适的地方（比如你的战斗 Hook、回合开始 Hook、或 AfterRoomEntered 覆写中） 手动调用 GainCharge(amount) 来按自己的规则回复充能。 同样的思路也适用于触发方式：充能遗物不绑定右键触发， 由创作者自己决定何时调用 DoChargeRelicEffect()（详见触发与 Hook）。 

public sealed class CustomChargeRelic : PlusChargeRelic
{
    public CustomChargeRelic() { TotalCharge = 3; }

    // 关闭默认的进房间 +1
    public override bool AutoCharge => false;

    // 改为：每场战斗结束时充能 +2
    public override Task AfterCombatEnd(CombatRoom room)
    {
        GainCharge(2);
        return Task.CompletedTask;
    }

    public override async Task MainEffect() { /* 你的效果 */ }
}

充能操作 API

方法签名作用
GainChargevoid GainCharge(int amount = 1)增加指定层数充能（内部走 NowChargeUpgrade，经过全部充能数值 Hook 修正）。
SetChargevoid SetCharge(int now, int total)直接设置当前充能与最大充能。
SetChargevoid SetCharge(int amount)把当前充能与最大充能都设为同一值（即直接充满）。
SpendChargeasync void SpendCharge()消耗充能（消耗量经 Plus_ModifyChargeSpend 系列 Hook 修正，默认清空全部）。
NowChargeUpgradeasync void NowChargeUpgrade(int amount = 1)充能核心入口：修正增量 → 触发 Plus_AfterChargeGain → 累加 → 触发 Plus_OnChargeChanged → 刷新满充状态。

内部流程（NowChargeUpgrade）：

  1. 取「解析后最大充能」：TotalCharge 经过 Plus_ModifyMaxCharge 系列修正。
  2. 取「解析后充能增量」：amount 经过 Plus_ModifyChargeUpgrade 系列修正。
  3. 未满充时播放闪光（Flash()）。
  4. 触发 Plus_TriggerAfterChargeGain（通知外界本次获得了多少充能）。
  5. 累加充能（不超过最大充能）。
  6. 触发 Plus_TriggerOnChargeChanged（旧值 → 新值）。
  7. 刷新满充状态（必要时触发 Plus_OnChargeFullyCharged）。

充能消耗（SpendCharge）

触发效果后调用 SpendCharge() 消耗充能。默认消耗量 = 解析后的最大充能（即清空全部）。 消耗量同样经过 Plus_ModifyChargeSpend 系列 Hook 修正， 所以你可以让遗物「每次只消耗 1 点充能」而不是清空。

满充状态与状态切换

基类通过 CalculatedIsFullyCharged() 检测充能是否达到上限，并：

  • 满充时：遗物 Status 变为 RelicStatus.Active，触发 Plus_OnChargeFullyCharged。
  • 不再满充时：恢复 RelicStatus.Normal，触发 Plus_OnChargeNoLongerFullyCharged。
