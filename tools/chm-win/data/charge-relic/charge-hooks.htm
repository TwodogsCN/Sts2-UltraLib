触发与 Hook
本文档说明充能遗物从「玩家右键」到「效果执行」的完整链路， 以及 UltraLib 为充能遗物提供的全部 Hook。核心结论：效果逻辑写 MainEffect， 这样触发次数等 Hook 会自动生效。

右键触发链路

完整链路如下（右键捕获、Action 同步、Hook 分发由 UltraLib 自动接通；右键只是触发方式之一，你完全可以用自动触发等其他方式调用 DoChargeRelicEffect）：

  1. 右键捕获：RelicRightClickPatch 在遗物 UI 上监听右键/取消键，校验归属玩家后触发。
  2. Action 入队：构造 RelicRightClickAction（GameAction）入队，联机时通过 RelicRightClickSyncNet 同步到其他客户端，保证全端一致执行。
  3. Hook 分发：执行 Plus_TriggerRelicRightClick，把所有 IPlusHooks 监听者（包括遗物自身）的 Plus_RelicRightClick 逐个调用。
  4. 创作者接线：PlusChargeRelic 基类不写死触发方式——由创作者自己决定何时触发（右键、自动、回合开始等均可）：在触发点检查满充后调用 DoChargeRelicEffect()，再调用 SpendCharge() 消耗充能（见下方示例）。
// 触发接线（示例：右键触发）——触发方式由你决定，可以是右键 / 自动 / 回合开始等
public override async Task Plus_RelicRightClick(RelicModel relicModel, NRelicInventoryHolder? holder)
{
    if (!IsFullyCharged) return;   // 未满充不触发

    await DoChargeRelicEffect();  // 执行 MainEffect（含重复次数 Hook）
    SpendCharge();               // 消耗充能
}

DoChargeRelicEffect 执行流程

DoChargeRelicEffect 是充能遗物效果的总入口。它会依次做三件事： ① 计算重复次数 → ② 触发前后全局 Hook → ③ 循环执行 MainEffect。 伪代码： 

async Task DoChargeRelicEffect()
{
    // ① 计算重复次数（默认 1，可被 Hook 修正）
    int times = 1;
    times += Plus_TriggerModifyChargeRepeatTimesAddictive(times, ...);
    times  = (int)(Plus_TriggerModifyChargeRepeatTimesMultiplicative(times, ...) * times);
    times  = (int)Plus_TriggerModifyChargeRepeatTimes(times, ...);

    // ② 总触发前
    await Plus_TriggerBeforeChargeTotallyEffected(...);

    // ③ 循环执行效果
    for (int i = 0; i < times; i++)
    {
        await Plus_TriggerBeforeChargeEffected(...); // 单次触发前
        await MainEffect();                          // ← 你的效果写这里
        await Plus_TriggerAfterChargeEffected(...);  // 单次触发后
    }

    // 总触发后
    await Plus_TriggerAfterChargeTotallyEffected(...);
}

为什么效果必须写在 MainEffect？ 因为「触发次数」由 DoChargeRelicEffect 统一计算并循环调用 MainEffect。 如果你把效果写在别处（例如 Plus_RelicRightClick 里直接写）， 那么 Plus_ModifyChargeRepeatTimes 系列 Hook 和 Before/AfterChargeEffected 单次 Hook 都无法正确包裹你的效果。

充能相关 Hook 参考

以下 Hook 定义在 IPlusHooks，你可以在自己的遗物/能力/单例模型中覆写；基类 PlusRelicModel 已提供空实现，只覆写需要的即可。

数值修正类（Modify）

Hook作用
Plus_ModifyMaxCharge / ...Multiplicative / ...Addictive修正最大充能值（依次为 管道、乘法、加法 三段式）。
Plus_ModifyChargeUpgrade / ...Multiplicative / ...Addictive修正每次充能获得量（默认 +1）。
Plus_ModifyChargeSpend / ...Multiplicative / ...Addictive修正每次触发消耗的充能量（默认消耗 = 最大充能）。
Plus_ModifyChargeRepeatTimes / ...Multiplicative / ...Addictive修正触发效果重复次数（默认 1 次）。

事件类（Trigger）

Hook触发时机
Plus_OnChargeFullyCharged充能到达满值时。
Plus_OnChargeNoLongerFullyCharged充能不再满值时（如消耗后）。
Plus_OnChargeChanged充能数值变化时（参数：旧值、新值）。
Plus_AfterChargeGain每次获得充能后（参数：获得量）。
Plus_AfterChargeSpend每次消耗充能后（参数：消耗量）。
Plus_BeforeChargeEffected / Plus_AfterChargeEffected单次效果执行前 / 后（若重复次数 > 1 会多次触发）。
Plus_BeforeChargeTotallyEffected / Plus_AfterChargeTotallyEffected整个效果流程开始前 / 结束后（只触发一次）。

典型覆写示例

// 例：另一个遗物让本充能遗物多触发 1 次
public override decimal Plus_ModifyChargeRepeatTimesAddictive(decimal a, Player p, RelicModel r)
{
    if (r is ExampleChargeRelic)
        return a + 1m;
    return a;
}

// 例：充能满时给一个提示
public override Task Plus_OnChargeFullyCharged(Player p, RelicModel r)
{
    GD.Print($"[{r.Id}] 充能已满，右键触发！");
    return Task.CompletedTask;
}
