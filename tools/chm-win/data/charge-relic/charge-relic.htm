新功能 [充能遗物] — 总览
充能遗物（ChargeRelic）是 UltraLib 提供的一类特殊遗物基类 PlusChargeRelic。 它的核心玩法是：遗物会随着时间自动积攒「充能」，充能满后玩家右键遗物触发一次强力效果并消耗充能。 本文档介绍它的设计思路、如何创建、默认行为以及可自定义的部分。

设计思路

普通遗物拿到后效果是「永久」或「一次性」的；充能遗物则像一座小「电池」—— 它本身不做任何事，而是不断「充电」（回复充能），充能满时玩家主动右键「放电」（触发效果）， 之后重新开始积攒。这样就形成 充能 → 满充 → 右键触发 → 清空 → 再充能 的循环节奏。

  • 回复充能：默认在进入每个房间时自动 +1 充能（见 充能机制详解）。
  • 触发效果：充能满时右键遗物，执行你写在 MainEffect 里的逻辑（见 触发与 Hook）。
  • 消耗充能：触发后清空充能（可自定义消耗量），重新开始积攒。

如何创建一个充能遗物

继承 PlusChargeRelic，然后只需要写 两样东西：最大充能值，以及触发效果 MainEffect。 默认情况下其余行为（自动充能、充能条 UI）都由基类和 Patch 自动完成。 

public sealed class ExampleChargeRelic : PlusChargeRelic
{
    public ExampleChargeRelic()
    {
        // 最大充能：需要 5 点充能才能触发
        TotalCharge = 5;
    }

    // ① 触发接线（示例：右键触发；也可以是自动/回合开始等，由你决定）
    public override async Task Plus_RelicRightClick(RelicModel relicModel, NRelicInventoryHolder? holder)
    {
        if (!IsFullyCharged) return;

        await DoChargeRelicEffect(); // 执行 MainEffect（含触发次数 Hook）
        SpendCharge();                // 消耗充能
    }

    // ② 充能触发时的实际效果
    public override async Task MainEffect()
    {
        await CreatureHelper.Damage(
            new BlockingPlayerChoiceContext(),
            Owner.Creature.CombatState.HittableEnemies.First(),
            20m, ValueProp.None, Owner.Creature, null, null);
    }
}

注意：MainEffect 是效果的核心入口，把充能触发时的实际效果逻辑写在这里。 触发方式不写死——右键触发、自动触发、回合开始触发等都由创作者自己决定： 在任意你想触发的地方，检查 IsFullyCharged（满充）后调用 DoChargeRelicEffect() 执行效果， 再调用 SpendCharge() 消耗充能即可。只要效果写在 MainEffect、 并通过 DoChargeRelicEffect 执行，UltraLib 的「触发次数」Hook（Plus_ModifyChargeRepeatTimes 系列） 就能自动、正确地包裹并重复执行你的效果，你无需自己处理次数逻辑。 详见 DoChargeRelicEffect 执行流程。

完整行为一览

行为默认情况如何修改
充能回复进入每个房间自动 +1覆写 AutoCharge = false 关闭；或覆写 Plus_AfterRoomEntered 自定义回复逻辑
最大充能默认 1设置 TotalCharge，或用 SetCharge(now, total)
充能显示遗物下方显示充能进度条覆写 UseChargeBarDisplay = false 回退为数字显示
触发条件右键时检查 IsFullyCharged，未满充不触发在 Plus_RelicRightClick 里自定义触发条件
触发效果右键接线中调用 DoChargeRelicEffect() → 循环执行 MainEffect效果写 MainEffect；接线需自己覆写 Plus_RelicRightClick
触发次数默认 1 次覆写 Plus_ModifyChargeRepeatTimes 系列 Hook
充能消耗触发后清空全部充能覆写 Plus_ModifyChargeSpend 系列 Hook 调整消耗量
