UltraLib 更新日志
记录 UltraLib 的版本更新内容。最新版本见本页顶部。

v0.1.0（当前版本）

  • 发布首个基础版本：建立 UltraLib 基础库框架。
  • 新增 Plus* 抽象基类模型：PlusRelicModel、PlusPowerModel、PlusSingletonModel、PlusChargeRelic。
  • 新增 钩子系统（IPlusHooks / PlusHooks）：统一事件分发与数值修改管线。
  • 新增 Base/Utils 工具库：卡牌、能力、充能球、遗物、发现等常用操作封装。
  • 新增 动态变量：Empower（赋能）、Return（返回）、Rose 系列。
  • 新增 本地化支持：eng / zhs 双语文案。
  • 配套文档：在线 Wiki + 本 CHM 离线手册。
